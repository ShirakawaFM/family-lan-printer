家庭打印 · LAN 局域网版（{VER}）
================================

适合：手机和打印电脑连同一个 WiFi，只在家里用。不需要云服务器。

1. 安装 Python 3.10 或更高版本，安装时勾选 Add Python to PATH。
2. 打开命令行，进入本文件夹，执行：
   python -m pip install -r requirements.txt
3. 执行：
   python print_server.py
4. 控制台会显示内网地址，例如：
   http://192.168.1.100:5000
5. 手机连同一个 WiFi，浏览器打开这个地址，输入共享密码。
6. 把生成的 qr_wall.png 打印出来贴在打印机旁边，以后扫码即可。
7. 正式使用前，打开 print_server.py，把 ACCESS_PASSWORD 改成家里的强密码。

打印前会先进预览页，可以在里面调纸张、方向、页边距、缩放、字号和行距，
所见即所得，确认后再点「打印」，避免打废纸。

注意：不要双击 print_server.py 后马上关掉黑色窗口；窗口关掉服务就停了。
