# 家庭打印 · 公网部署傻瓜包

这个包用来把家里的打印网页安全地映射到公网，让手机用 4G/5G 也能打开。

> 适合：云服务器 + 家里 Windows 电脑 + 家用打印机。
>
> 不适合：完全不想买云服务器、不想做任何安全设置的人。

## 先看风险

公网部署后，互联网上的人也能访问到登录页。请务必：

1. 把 `print_server.py` 里的 `ACCESS_PASSWORD` 改成强密码，不要用 `123456`；
2. 使用本包生成的长随机 `frp token`；
3. 不要把公网地址贴到群里、朋友圈或公开网页；
4. 有条件一定按 `optional-https/HTTPS-可选教程.md` 加 HTTPS。

本包默认走 **frp TCP 映射 + HTTP**，配起来最省事，但 HTTP 下密码在公网上是明文传的。HTTPS 可选，但很建议加。

## 目录里有什么

```text
deploy-public/
├─ 00-先看-公网部署教程.md      ← 本文件
├─ 01-先填-部署信息.txt          ← 先用记事本填这个
├─ server/
│  ├─ 02-云服务器-运行这个.sh    ← 在云服务器上运行
│  └─ frps.toml.template         ← 手动部署时参考
├─ windows/
│  ├─ 03-家里电脑-运行这个.ps1   ← 在家里 Windows 上运行

└─ optional-https/
   ├─ HTTPS-可选教程.md
   └─ Caddyfile.template
```

## 整体结构

```text
手机 4G/5G
   │  http://（云服务器公网 IP）:（外网访问端口）
   ▼
云服务器 frps
   │  frp 控制端口（默认 7000）
   ▼
家里 Windows 电脑 frpc
   │  127.0.0.1:5000
   ▼
print_server.py → 默认打印机
```

## 第 0 步：填信息

打开 `01-先填-部署信息.txt`，把所有 `（）` 里的内容换成你自己的。

规则：

- 所有 `（...）` 都要替换，最后不要保留括号和提示文字；
- 不知道的可以先留空，脚本会给出默认值；
- `frp token` 可以让云服务器脚本自动生成，生成后抄到填写单里；
- 这个文件只给自己看，不要提交到 GitHub。

## 第 1 步：准备云服务器

建议配置：

- Ubuntu 22.04 / 24.04，1 核 1G 就够；
- 有公网 IPv4；
- 能用 SSH 登录；
- 安全组/防火墙放行：
  - SSH：`（SSH 端口，默认 22）/TCP`
  - frp 控制端口：`（默认 7000）/TCP`
  - 外网访问端口：`（默认 6000）/TCP`
  - 如果后面上 HTTPS：再放行 `80/TCP`、`443/TCP`

> 云厂商的“安全组”必须先放行，否则脚本跑成功，手机也连不上。

把 `server/02-云服务器-运行这个.sh` 上传到服务器。可以在自己电脑上执行：

```bash
scp -P （SSH端口） "deploy-public/server/02-云服务器-运行这个.sh" （SSH用户名）@（云服务器公网IP）:/root/
```

SSH 登录服务器：

```bash
ssh -p （SSH端口） （SSH用户名）@（云服务器公网IP）
```

运行：

```bash
sudo bash /root/02-云服务器-运行这个.sh
```

脚本会依次询问：

| 脚本提示 | 填什么 |
| --- | --- |
| `frp 控制端口（默认 7000）` | 直接回车用 7000，或填你放行的端口 |
| `外网访问端口（默认 6000）` | 手机访问用的端口，直接回车用 6000 |
| `frp token（直接回车自动生成）` | 建议直接回车，让脚本生成 |

运行成功后，终端会显示一长串 `frp token`，**复制下来**，下一步和填写单都要用。

检查服务：

```bash
systemctl status frps --no-pager
journalctl -u frps -n 50 --no-pager
```

如果服务器开了 UFW，还要放行端口：

```bash
sudo ufw allow （frp 控制端口）/tcp
sudo ufw allow （外网访问端口）/tcp
sudo ufw reload
```

## 第 2 步：配置家里 Windows 电脑

前提：

- 这台电脑已经能局域网打印；
- 已经装好 Python 依赖：
  ```bat
  python -m pip install -r requirements.txt
  ```

把整个 `deploy-public` 文件夹放到 `print_server.py` 所在目录下，例如：

```text
D:\家庭打印\
├─ print_server.py
├─ requirements.txt
├─ qr_wall.png
└─ deploy-public\
   ├─ 00-先看-公网部署教程.md
   └─ windows\
      └─ 03-家里电脑-运行这个.ps1
```

在 `print_server.py` 所在目录打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\deploy-public\windows\03-家里电脑-运行这个.ps1"
```

脚本会询问：

| 脚本提示 | 填什么 |
| --- | --- |
| `云服务器公网 IP（请填写）` | 第 1 步的云服务器 IP |
| `frp 控制端口（默认 7000）` | 和第 1 步一致 |
| `frp token（请粘贴）` | 第 1 步终端显示的长串 |
| `外网访问端口（默认 6000）` | 和第 1 步一致 |
| `本机打印服务端口（默认 5000）` | 一般直接回车 |

脚本会自动：

- 下载 `frpc.exe` 到 `frp\`；
- 生成 `frp\frpc.toml`；
- 生成 `启动家庭打印.bat`；
- 在“启动”文件夹放一个快捷方式，下次登录自动启动；
- 立即启动打印服务和 frpc；
- 检查 `http://127.0.0.1:5000` 是否正常。

看到 `本机打印服务正常` 和 `公网地址` 就成功了。

## 第 3 步：手机实测

1. 手机**关掉 WiFi**，只用 4G/5G；
2. 浏览器打开：
   ```text
   http://（云服务器公网 IP）:（外网访问端口）
   ```
3. 输入家里的打印密码；
4. 打一行字测试；
5. 能出纸就说明公网链路通了。

## 第 4 步：安全设置

- 打开 `print_server.py`，把 `ACCESS_PASSWORD = "123456"` 改成强密码；
- 改完重启打印服务（运行 `启动家庭打印.bat` 或重新执行本包脚本）；
- 不要把公网地址和密码发到群里；
- 不需要公网时，在服务器执行 `sudo systemctl stop frps` 即可关闭入口；
- 想更安全，继续看 `optional-https/HTTPS-可选教程.md`。

## 第 5 步：常见问题

### 手机显示“无法访问此网站 / 连接被拒绝”

按顺序检查：

1. 云服务器安全组是否放行 `（外网访问端口）/TCP`；
2. `systemctl status frps` 是否 `active (running)`；
3. 家里电脑 `frpc.exe` 是否在运行；
4. `frp\frpc.log` 有没有报错；
5. Windows 电脑是否睡眠/关机；
6. 打印服务 `http://127.0.0.1:5000` 是否正常。

### 提示 `token in login request does not match`

家里 `frpc.toml` 和服务器 `frps.toml` 里的 token 不一样。重新复制第 1 步的 token，重跑 Windows 脚本。

### 提示 `port already used`

端口被别的程序占用。换一个外网访问端口（比如 6001），重新在两台机器上填写一致。

### 家里能打开，手机 4G 打不开

说明打印服务正常，问题在 frp 或云服务器：

- 安全组没放行；
- frps 没启动；
- frpc 没连上；
- token 不一致；
- 云服务器公网 IP 填错。

### 能打开登录页，但点打印失败

通常是家里电脑睡眠、打印服务被关掉、打印机离线。先看打印页面的失败原因和解决办法。

### 服务器重启后 frps 会自启吗

会。脚本创建了 systemd 服务，并设置了开机自启。检查：

```bash
systemctl is-enabled frps
```

### 想彻底关闭公网入口

```bash
sudo systemctl disable --now frps
```

家里 Windows 删除“启动”文件夹里的 `家庭打印公网版.lnk`，再删除 `frp` 文件夹即可。

## 手动部署

不想用脚本时，可以参考：

- `server/frps.toml.template`
- `windows/frpc.toml.template`

把 `（）` 里的内容替换成真实值，放到 frp 目录，然后分别运行：

```bash
/opt/frp/frps -c /opt/frp/frps.toml
```

```bat
frpc.exe -c frpc.toml
```

## 最后提醒

- 公网 HTTP 的密码不是加密传输，强烈建议加 HTTPS；
- 不要把云服务器 root 密码、frp token、家庭打印密码写进公开仓库；
- 这个工具只适合家庭自用，不要拿去做对外打印服务。
